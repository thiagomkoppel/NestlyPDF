# MVP Scope

## Included

- Open local PDF.
- Open local `.docx`, converted to PDF in the browser at import time (ADR-006).
- Multi-page rendering and thumbnails.
- Zoom and page navigation.
- Text boxes.
- Checkmark and cross.
- Date element.
- Drawn, typed, and image-based signatures.
- Initials.
- Image placement.
- Whiteout and replacement text.
- Move, resize, duplicate, and delete elements.
- Undo and redo.
- Existing AcroForm field filling for common field types.
- Rotate, reorder, duplicate, and delete pages.
- Insert pages from another PDF.
- Download completed PDF.
- Unsaved-change warning.
- Session cleanup.
- Desktop, tablet, and mobile support.

## Explicitly excluded

- Accounts and authentication.
- Cloud storage.
- Server-side document processing.
- Collaboration.
- Email sending.
- Signature requests and tracking.
- OCR.
- Secure redaction.
- True arbitrary editing of existing PDF text.
- Legacy binary `.doc` (Word 97-2003) import.
- Selectable or searchable text in converted Word documents.
- Password cracking or unauthorized password removal.
- PSD support.
- AI-assisted document completion.
